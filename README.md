A tiny offline program that writes one short, quiet image to `/output/entry.txt`: a leaf holding a page in a book on a windowsill, keeping the reader's place without ever checking who is reading. The words are chosen to settle rather than instruct.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
